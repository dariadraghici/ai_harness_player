You prepare a game-playing bot for a two-player text game it has never seen. Read the rules and produce a compact, exact profile. Your answer is checked by code against the rules text, and parts of it are used directly in matches, so precision matters more than style.

Game families (pick exactly one, or "unknown" when none fits):
- bluff: hidden information, betting, bluffing, probabilities
- deals: negotiation, trust and betrayal, auctions with private values
- read_opponent: simultaneous moves, patterns, mixed strategies
- guessing: deduction from feedback
- think_ahead: perfect-information board games, search, tactics
- truth: answer from a given document; an invented answer costs more than "unknown"
- guardrails: the rules name a forbidden subject; never mention it, still answer the rest

What each field is used for:
- family: selects our chat tactics and later the search engine. A wrong family costs games.
- family_quote: a SHORT verbatim quote (5 to 25 words) copied character for character from the rules that supports the family. Code checks that it is really in the rules.
- perfect_information: true when both players see the whole game state; false when anything is hidden from a player (private cards, secret numbers, hidden choices).
- simultaneous: true when both players choose at the same time without seeing the other's choice; false when players alternate.
- turn_structure: "alternating", "simultaneous", or "talk_is_move" (the chat message itself is the move).
- hidden_information: one short phrase saying what is hidden and from whom, or "none".
- chance: one short phrase saying what is random (dealt cards, drawn secrets, dice), or "none".
- speech_restrictions: ONLY what the rules literally forbid a player to say or mention, as one short plain sentence starting with "Never", without commentary. Empty string when the rules forbid nothing. A filter applies it to every chat line and action we send.
- action_format: the exact syntax of one action, copied or closely paraphrased from the rules.
- action_regex: a Python regular expression that every valid action string fully matches (used with re.fullmatch), or an empty string if you cannot write one.
- example_action: one concrete valid action string, exactly as it would be sent, with no quotes around it. It is SENT AS OUR MOVE when everything else fails, so it must be valid as is in a typical position; prefer an action the rules show.
- playbook: at most 12 short lines, at most 900 characters in total: how to win, what to say in chat (offense), what to watch in the opponent's chat (defense), what never to say. It is pasted into every move decision, so keep it short.

Answer with ONLY one JSON object with exactly these keys, no other text:
{"family": "...", "family_quote": "...", "perfect_information": true, "simultaneous": false, "turn_structure": "...", "hidden_information": "...", "chance": "...", "speech_restrictions": "...", "action_format": "...", "action_regex": "...", "example_action": "...", "playbook": "..."}
